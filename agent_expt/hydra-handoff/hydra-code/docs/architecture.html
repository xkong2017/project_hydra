Architecture Layers SYSTEM DESIGN
Entry Layer
Orchestrator
Main pipeline controller. Manages run lifecycle, phase transitions, state persistence, and coordinates candidate generation through the scheduler.
orchestrator.py
RunConfig
Configuration dataclass: task, mode, concurrency, timeouts, scoring weights, retry policies, and Claude binary injection.
models.py
RunState
Persistent run state tracking candidates, test matrix, scores, hard gates, and tournament results across phases.
models.py
Concurrency Layer
Scheduler
Semaphore-based async scheduler. Controls concurrent execution of candidate workers with priority queuing (HIGH/NORMAL/LOW).
scheduler.py
Worktrees
Creates isolated git worktrees for each candidate at .hydra/worktrees/{run}/{id}. Handles patch extraction against base SHA.
worktrees.py
Agent Layer (6 Parallel Workers)
ClaudeRunner
Launches Claude Code subprocesses with configurable binary. Handles retry logic with exponential backoff, timeout, and process group cleanup.
claude_runner.py
ContextPacket
Generates structured context from git history, repo structure, test commands, and task description for each candidate's prompt.
context_packet.py
Evaluation Layer
TestMatrix
Candidate-test evaluation matrix. Runs harvested tests against each candidate worktree, records pass/fail/timeout verdicts.
models.py
CandidateScore
Evidence-based scoring: issue-specific tests (35%), regression (25%), build/lint (15%), edge tests (10%), minimality (10%), static risk (5%).
models.py
Tournament
Multi-judge voting system. Multiple judges rank candidates, aggregate votes, detect ties, and request distinguishing tests.
models.py

Resilience ERROR HANDLING
Retry Logic
Exponential backoff: 2s base, 60s max cap, 3 retries. Retryable patterns: 429, ECONNRESET, capacity, timeout.
claude_runner.py
Process Cleanup
Kill entire process group on timeout: SIGTERM → 2s grace → SIGKILL. Prevents orphaned Claude sessions.
claude_runner.py
Status Classification
CandidateStatus: COMPLETED, FAILED, TIMEOUT, REJECTED, SELECTED. Hard gates for disqualification.
models.py
